# نَبض | NABD Finance

نَبض لوحة مالية محلية للتجار والمشاريع الصغيرة. تساعد على تنظيم الحركات المالية، متابعة التدفقات النقدية، مراجعة الالتزامات القادمة، وتجربة سيناريوهات مالية قبل اتخاذ القرار.

## المزايا

- لوحة تحكم تعرض الرصيد الحالي والوارد والصادر.
- استيراد الحركات من ملفات CSV وتنزيل قالب جاهز.
- حساب الرصيد المتوقع لمدة 14 يومًا بالاعتماد على الحركات المجدولة.
- تنبيهات عن الرصيد السالب والدفعات الكبيرة وتركيز قنوات التحصيل.
- مختبر سيناريوهات لتجربة التحصيل الإضافي وخفض المصروفات وتأجيل الدفعات.
- واجهة عربية وإنجليزية مع حفظ اللغة المختارة.
- تصدير نسخة احتياطية وتقرير حسابات.
- حفظ محلي داخل المتصفح، دون إرسال البيانات المالية إلى خادم خارجي.
- تطبيق ويب قابل للتثبيت ويعمل دون اتصال بعد الزيارة الأولى.

## ملاحظة حول التوقعات

التوقع الحالي حساب رياضي مبني على الرصيد الناتج من الحركات المكتملة، ثم إضافة الوارد المجدول وطرح الصادر المجدول حسب التاريخ. لا يتنبأ بمبيعات أو مصروفات لم يسجلها المستخدم، ولا يستخدم نموذج تعلم آلي. النتائج تقديرية وتعتمد على اكتمال وصحة البيانات المدخلة.

## التشغيل

لا يحتاج المشروع إلى npm أو خطوة بناء. شغّله بخادم ملفات ثابت، مثل:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## النشر

### Render Static Site
- Build command: اتركه فارغًا.
- Publish directory: `.`

يمكن نشر المشروع كذلك على GitHub Pages أو Netlify أو Cloudflare Pages أو أي استضافة Static.

## صيغة CSV

```text
date,amount,type,category,description,channel,status
```

- `type`: `income` أو `expense`
- `status`: `completed` أو `scheduled`
- `channel`: `cash` أو `zaincash` أو `bank` أو `other`

## الخصوصية وحدود الاستخدام

تتم معالجة البيانات وحفظها محليًا في المتصفح. لا توجد حسابات مستخدمين أو مزامنة سحابية افتراضيًا. نَبض أداة تنظيم ومتابعة مالية، وليس بديلاً عن المحاسب أو الاستشارة المالية والقانونية. يجب مراجعة البيانات والنتائج قبل اتخاذ قرارات مالية مهمة.
